## 열 모델 수식과 물성값 (가정)

정상상태, 칩(실리콘 다이) 한 층의 평면 전도 + 아래로 빠지는 열:

    k·t·∇²T − h·(T − T_amb) + q'' = 0      (옆면 단열)

| 기호 | 값 | 근거 | 상태 |
|---|---|---|---|
| 칩 크기 | 10 mm × 10 mm | 설명용 대표값 | [가정] |
| t (실리콘 두께) | 0.5 mm | 설명용 대표값 | [가정] |
| k (실리콘 열전도율) | 150 W/m·K | 상온 실리콘 대표값 (온도에 따라 달라짐, 무시) | [가정] |
| h (아래쪽 등가 열전달계수) | 20,000 W/m²·K | 칩 면적 1 cm² 기준 아래쪽 전체 열저항 0.5 K/W에 해당하도록 정함 | [가정] |
| T_amb | 25 °C | 기준 온도 | [가정] |

- 확산 길이 1/m = √(k·t/h) ≈ 1.9 mm, 칩 한 변의 약 1/5 → 핫스팟이 옆으로 퍼지는 정도가 격자에서 보일 만한 크기
- 이 값들은 실제 특정 칩이 아님. 결과는 "이 가정에서"라고 적음

## 손계산 검증 케이스
1. **균일 전력:** 옆으로 흐를 열이 없음 → 모든 칸에서 ΔT = q''/h (정확해)
2. **한쪽 띠에만 전력 (1D):** 0 < x < a에 q'', 나머지는 0, 양 끝 단열 → 쌍곡선 함수 해석해와 비교 (최고 온도 상승, 최저 온도 상승)
3. **에너지 보존:** 아래로 빠진 열의 합 = 넣은 전력의 합
