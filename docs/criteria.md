## 2. 열 모델

정상상태, 실리콘 다이 단층의 평면 전도와 하부 방출:

```
k·t·∇²T − h·(T − T_amb) + q'' = 0      (측면 단열)
```

| 기호 | 값 | 근거 | 구분 |
|---|---|---|---|
| 칩 크기 | 10 mm × 10 mm | 대표값 | 가정 |
| t (실리콘 두께) | 0.5 mm | 대표값 | 가정 |
| k (실리콘 열전도율) | 150 W/m·K | 상온 실리콘 대표값 (온도 의존성 무시) | 가정 |
| h (하부 등가 열전달계수) | 20,000 W/m²·K | 1 cm² 기준 하부 열저항 0.5 K/W에 해당 | 가정 |
| T_amb | 25°C | 기준 온도 | 가정 |

- 확산 길이 √(k·t/h) ≈ 1.9 mm (칩 한 변의 약 1/5)로, 핫스팟의 횡방향 확산이 격자에서 구분되는 크기다.

**검증 케이스**
1. 균일 발열: 횡방향 열 흐름이 없으므로 모든 칸에서 ΔT = q''/h
2. 1D 띠 발열: 0 < x < a에만 q'', 양 끝 단열 → 쌍곡선 함수 해석해와 비교
3. 에너지 보존: 하부 방출 열량의 합 = 입력 전력의 합
